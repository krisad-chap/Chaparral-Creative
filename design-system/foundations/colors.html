Contrast & pairing

Measured ratios, not estimates. Everything above the rule meets WCAG AA for body text; the last two are constrained. Slate 40 sits below AA on purpose — it is for disabled controls and decorative rules, which WCAG exempts, and must never carry text a user has to read.

Ink on White18.0:1 — AAA, any size
Slate on White11.0:1 — AAA, any size
Sage on White7.1:1 — AAA, any size
Slate 60 on White4.6:1 — AA, any size
White on Ink18.0:1 — AAA, any size
Slate on Bone9.7:1 — AAA, any size
White on Signal Blue3.2:1 — large text / UI only
Slate 40 on White2.5:1 — decorative & disabled only
DoUse Signal Blue as a fill behind white text at 18px+ or on buttons and chips, where WCAG treats it as a UI component.
Don'tSet body copy in Signal Blue on white, or white body copy on Signal Blue — it fails AA at 16px.
DoUse Slate 60 #697786 for helper text, captions and placeholders. It is the lightest grey that still passes AA.
Don'tReach for Slate 40 to make text "quieter". If it needs to be readable, it needs 4.5:1.
