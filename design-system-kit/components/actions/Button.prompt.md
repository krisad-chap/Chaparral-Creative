Use Button for any action; `primary` for the single main action per view, `secondary` beside it, `inverse` on Ink backgrounds.

```jsx
<Button variant="primary" size="lg" href="/contact">Book a free consultation</Button>
<Button variant="secondary">See our work</Button>
```

Variants: primary, secondary, ink, ghost, inverse. Sizes: sm/md/lg. `block` fills its container. One primary per view — Blue is a 10% accent.
