Use Card for service tiles, case-study teasers and grouped content on White or Bone bands.

```jsx
<Card title="SEO & web optimization" text="Audit first, then the plan the data supports." interactive footer={<TextLink href="/seo">See the service</TextLink>} />
```

Use `raised` for cards floating on Bone, bordered (default) on White. `interactive` only when the card itself navigates.
