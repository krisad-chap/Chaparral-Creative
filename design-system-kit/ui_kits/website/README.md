# UI kit — chaparralcreative.com

A click-through recreation of the marketing site, composed from the design-system primitives
(`Nav`, `Hero`, `Section`, `Container`, `Card`, `Stat`, `Table`, `Badge`, `Alert`, `Field`, `Input`,
`Select`, `Textarea`, `Checkbox`, `Button`, `TextLink`, `Tabs`, `Breadcrumb`, `Text`, `Eyebrow`).

| File | Surface |
|---|---|
| `Chrome.jsx` | Site header (inlined horizontal lockup) and Ink footer |
| `Home.jsx` | Ink hero, services grid, proof band, closing CTA |
| `Service.jsx` | Breadcrumb, service detail, deliverables table, reporting alert |
| `Work.jsx` | Sector tabs over case-study cards with stats |
| `Contact.jsx` | Lead form with validation and success state |
| `index.html` | Mounts all four with working navigation and a submittable form |

Layout comes from `design-system/components/sections.html`, `navigation.html`, `cards.html` and
`forms.html` in the source repo. Copy on these screens follows `brand/guidelines.md`; nothing here
is a live page from the site, so treat the wording as on-brand placeholder.
